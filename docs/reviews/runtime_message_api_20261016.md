完整树为 `dcea169922f3beb6831673a9f5000f0b5954aa83`。

## 分片入口补齐

新增 `tr_runtime_shard_message_cancel()` 和
`tr_runtime_shard_message_get_stats()`。消费者只持有 Runtime 分片和弱任务能力，
不取得可以绕过 Runtime 销毁的 MessageService 指针，不读取服务私有布局。

三个消息入口共用一个库内同步切换门禁。普通调用线程通过原有 Reactor
命令队列同步执行，所属 owner 内直接执行；其他 Reactor owner、通用任务工作线程
和 RPC 工作线程明确返回 `TR_ERR_STATE`，不能同步等待另一个执行域。
没有新线程池、结果队列、调度器或异步完成协议。

原 submit 直接调用 `tr_reactor_call()`，未在 Runtime 消息边界拒绝其他所有者。
同步切换可能与对向调用构成等待环；本轮阻断该路径，但没有声称实际复现了完整死锁。
对父 Reactor 已释放、预算外壳仍被保留的分片，统一返回 `TR_ERR_CLOSED`，
不把空 Reactor 的内部参数错误泄露为 `TR_ERR_INVALID`。

## 所有权及完成责任

- submit 仅在 `TR_OK` 消费输入、发布任务句柄并接管一次完成；失败不消费输入。
- cancel 仅设置原执行器取消意图；不提前释放输入、结果或回调参数。
  终局已提交返回 `STATE`；错误分片、已释放槽位和旧实例/代次返回 `STALE`。
- stats 先在目标 owner 的局部变量收集完整结果，仅 `TR_OK` 发布；任何失败
  保留调用者输出原状。快照不是预算预约、对象引用或停止/销毁屏障。

普通调用线程收到成功返回之前，原 owner 可能已经交付完成。回调参数必须事先
发布，任务句柄输出存储不能放在可能被回调提前销毁的参数对象里。
保留原有停止域 `OWNER_STOPPED` 终局与外部生命周期串行化契约；弱句柄不允许
与 Runtime 的最终销毁并发使用。取消仍为协作式，不承诺抢占后端调用。

## 新增真实集成测试

`test_runtime_message_api` 专门验证 Runtime 操作组合，不重复执行器原语测试。
使用两台真实 Reactor、真实消息服务、真实任务执行器及 Zstandard：

1. 禁用、尚未启动、已停止及部分销毁时三个操作的状态与失败不变性；
   无效参数和统计输出原样保留。
2. 在首个真实压缩调用之后固定工作者，同时保留一条排队任务；读取
   `running=1 / queued=1 / outstanding=2`，满载拒绝不消费输入或改变当前预算。
3. 通过分片入口取消运行与排队任务；完成之前不释放输入或参数，最终在
   原 owner 上各交付一次取消、无成功载荷。完成回调内可查询快照，取消自身
   已提交终局返回 `STATE`，回调返回前槽位仍占用。
4. 另一分片不能取消真实任务能力；另一 owner 和真实通用工作线程不能
   进入同步切换。测试包装只在被禁止的路径捕获尝试，合法路径调用真实函数。
   RPC 工作线程门禁由同一条件实现，本轮未新增真实 RPC 处理器专属场景。
5. 满载拒绝后在所属 owner 内重试成功；固定复用槽位的新任务，旧代次取消
   返回 `STALE`，新任务仍成功并能独立解码。Runtime 重启后旧实例同样失效。
6. 保留成功输出跨停止/重启及部分销毁；两个 Reactor 已回收时仍可读取输出，
   三个消息入口一致拒绝，最后引用释放后 Runtime 完整销毁。

仅该新目标增加 `tr_reactor_call` 与 `ZSTD_compressStream2` 链接包装。
生产库不添加故障钩子；既有回收测试及其故障注入保持不变。

## 本地实际证据

从独立只读诊断分支取得固定源码快照，核对 286 个 Git blob 和完整树。
诊断工作流不进入功能 PR，不读取或归档凭证。环境未安装 Xmake；本地根据
`xmake.lua` 的 36 个实际生产源交叉编译，不能称为正式 Xmake 构建。

| 验证 | 实际结果 |
| --- | --- |
| GCC 14.2 / Clang 17，O0/O2 | 四组完整生产源码编译及新测试通过 |
| GCC O2 新测试重复 | 20/20 通过 |
| Clang ASan/UBSan（默认泄漏检查） | 新集成测试通过，无诊断 |
| GCC TSan，非 PIE | 新集成测试通过，无诊断 |
| 修改后的 Runtime，两套本地静态分析 | 无诊断，未改变告警基线 |
| 相关既有 runtime/message_service/task_executor/runtime_message_recovery | 四个目标均通过 |

四个仅在本地构建的错误变体均被拒绝：删除执行域门禁、删除部分销毁状态
归一化、取消不提交意图、失败提前覆盖统计输出。这是测试有效性的反向证据，
不是四项既有生产缺陷的宣称。变体不进入最终源树。

本地 Zstandard 1.5.7 为预构建静态库，不声称其对象被 ASan/TSan 插桩。
固定 clang-format 18.1.8 校验新增/修改行。远端完整 Xmake、固定分析器、SDK
与全部测试的结果必须按本 PR 精确提交另行验收，不能继承 #260 的绿色。
