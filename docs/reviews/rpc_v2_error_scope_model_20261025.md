# RPC V2 ERR-A 错误作用域分类表与参考模型

日期：2026-10-25；关联 #242；版本 `2.0.0-dev.39`。

## 分类约定

| 错误 | 作用域与处置 | 条件和剩余义务 |
|---|---|---|
| 业务拒绝、方法不存在、调用级鉴权失败 | 调用级 `FINAL_STATUS` | 冻结调用终局并停止继续接收该调用的消息 |
| 单流消息语义或解码失败 | `RESET` 目标流 | 仅在帧边界、流标识可信且 RESET 已协商时使用；释放目标流存储并恰好归还一次连接信用 |
| 本地池或任务预算压力 | 明确资源拒绝 | 不冒充对端协议损坏；控制终局容量由后续 ERR-C 验证 |
| 无法信任的帧边界、连接协商错误、TLS 完整性失败 | 关闭连接 | 活动调用经所有者屏障收敛 |
| 未知私有状态损坏 | 默认关闭连接 | 只有后续能证明安全恢复域时才可改为隔离 |

模型使用不可变连接/调用快照，状态转换返回新快照。单流处置只改变目标调用；连接关闭只终结尚未终结的调用，已完成终局不会被覆盖。相同的 `STREAM_SEMANTIC` 故障在解析边界可信时只 RESET 目标流，在边界不可信、流标识不可证或 RESET 不可用时关闭连接。资源压力在模型中选择显式拒绝策略，不模拟另一种允许的有界等待策略。

## 验证

`scripts/test_rpc_v2_error_scope_model.py` 覆盖：

- 同一单流语义错误在可信与不可信帧边界下的不同处置范围；
- 流标识或 RESET 能力不可信时关闭连接；
- 业务拒绝和本地资源拒绝不影响同连接其他流；
- TLS、协商、帧边界和未知私有状态错误关闭所有活动调用；
- 连接关闭保留先前终局，重复关闭不产生第二次终局。

自测接入既有 `build-test (gcc)` Python 模型步骤，没有新增 CI job 或检查名称。该模型只作为 L1 协议设计参考；它没有驱动生产 C 代码，也不能证明运行时错误分类、连接信用归还或控制面容量正确。后续 ERR-B 至 ERR-E 和真实组件/网络组合验证仍然必要。
