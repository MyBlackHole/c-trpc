## 交付边界

分支实现覆盖普通 V2 RPC Client/Server mTLS 和 URI SAN 身份视图、transport-only
连接组 CONTROL/DATA mTLS 主体连续性、profile generation 的 graceful/revoke-old
轮换，以及多分片 Server 的准入屏障和失败关闭处理。TLS 更新不能把明文实例切换成
TLS，也不能降级成明文。默认仍为明文 TCP，TLS 失败关闭连接。

普通 RPC 连接和已接管的 CONTROL session 保留各自 TLS snapshot。Graceful 更新令新 TLS
接管采用新 generation；连接组需关闭并重连 CONTROL 才能使用新 snapshot，旧 CONTROL
不得接收新 Server generation 的 DATA。Revoke-old 会关闭旧 generation 的连接，因此
在途调用可能以连接错误结束。Profile 更新失败不改 `out_generation`。Server owner 的
pause/install/rollback 生命周期操作不可恢复时，实例保持 fail-closed，保留资源并只允许
destroy 重试。

公共门面消费端及 `tests/test_rpc_v2_sdk.c` 在四个编译器下都成功编译、链接和运行。
