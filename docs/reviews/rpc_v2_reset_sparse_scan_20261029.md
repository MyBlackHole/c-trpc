## 测量与已确认问题

此前 GCC Release 全量中的 `test_stream_reset` 曾在 120 秒超时；同一 ELF
随后原样定向通过并完整复验 95/95，原记录见[引用关联校验](rpc_v2_operation_reject_identity_20261029.md)。
本次调查不改超时或 40k 输入。perf 被系统拒绝，未调整系统安全参数；改用一次
可丢弃的 C 计数补丁，执行原 Xmake 专测。

在 max_streams=40000 的真实 Channel 场景，RESET 进度函数调用 82836 次，
访问 3313440000 个槽位，仅 81322 次遇到 RESETTING。旧实现在每次槽位检查时
都取/放 mutex，即使没有待处理 RESET 也扫描完整容量。该函数累计线程 CPU 为
66.653984770 秒，整个 OPEN/RESET 循环的进程 CPU 为 74.98083 秒；约占 88.895%。
函数计时包含同步发送/回调，不是独占 CPU 采样。它确认了系统性成本；不能把
上一次共享主机超时的全部耗时都归给这个函数，也未定量分离并行编译与频率影响。

## 实现与资源纪律

Channel 维护一个只表示 RESETTING 槽位的 uint32 位图，进入该状态时置位，
最终释放槽位时清位；异步变换仍持有槽位时保持置位，等原完成/回收屏障。
协议 RESET 与连接退役等待变换两条入口共用置位助手，清位集中在原 free 路径。
位图、槽状态、代次与游标继续由同一 mutex 保护，不增加锁或跨线程裸引用。

进度循环在原游标的剩余环形区间内查找首个置位，再执行原发送、重试、墓碑和
通知逻辑。查找只读紧凑位图，空槽不再各取一次锁；每槽在同一进度调用中至多
处理一次。发送成功后仍推进原数值游标；回调中新进入已走过区间的任务留待
下一次进度调用，原 retry/维护唤醒保持。REFUSED 优先级、固定 RESET 预留、
部分发送 FIFO、迟到输入隔离和退休通知顺序不改。

位图为 ceil(max_streams/32) 个 uint32，40k 为 5000 字节；指针增加也进入
sizeof(Channel) 的既有账目。位图接在两张索引的同一分配尾部，保持 uint32
对齐，不增加分配次数或运行期分配。构造先检查乘加溢出并预留完整 fixed_bytes，
失败按原构造清理归还，最终随索引释放后才退还预算。该账目是自有请求字节，
不表示 allocator/RSS 或全局跨域预算已验收。

## 回归与结果

既有专测增加 4097 槽场景，在真实流槽 4096、31、32、63、64、0 上依次 RESET，
覆盖字边界、尾部部分字和游标回绕。仅此测试链接 pthread_mutex_lock 包装，
保留真实锁；只统计被测 Reactor owner 的调用次数，owner 命令边界读取计数。
要求一次 RESET 的锁数少于容量，不能使用 CPU/墙钟阈值替代判定。

旧实现首项 8227 次锁，0.310 秒失败于 locks < capacity；新实现首次绿色运行
六项均 35 次，完整目标 1/1、原 40k 墓碑与全部 FIFO/多连接/信用/释放回归通过。
新增计数包装与原目标的 default、120000ms、普通 40k/TSan 5k 参数均保留。

Clang Release、GCC ASan/UBSan（含泄漏检查）、TSan、最终恢复的 GCC Release
全量各 95/95；命令耗时分别为 106.966、131.123、143.644、108.260 秒。每组
均核对六项锁次数；TSan 保留原 5k 墓碑，其余保留原 40k。源/测试/Xmake 三个
摘要在整个矩阵期间不变。[验证清单](data/reset_sparse_scan_20261029_validation.json)
保留每组计数、原始文件摘要和当前 ELF 摘要，确认正式 ELF 没有诊断符号。

最终 GCC Release 的原 40k 循环观察为墙钟 2766.39ms、进程 CPU 3545.98ms；基线
无探针的 dev.181 记录分别为 81658.39/82432.32ms。只比较同一内层循环，候选
全测试额外包含边界回归，且锁包装在 40k 段关闭计数但仍有入口判断；共享主机、
预热/编译环境也不同。保留数据，不据单次差异宣布 RPC 吞吐、尾延迟、固定机器
容量或跨平台改善；完整发布门槛与 #247 仍需其约定的负载和硬件验收。

内联审查覆盖两条 RESETTING 入口、最终清位、slot/generation 复用、构造失败、
索引布局与回调重入的扫描顺序。32 位/其他架构的运行证据未取得。CTM1 共同描述
协商仍待设计审阅，服务目标/Attempt、生成工具与桩、后端等价比较、TLS-E 与
