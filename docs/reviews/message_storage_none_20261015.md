## 2. 状态与责任

```text
EMPTY --reserve--> RESERVED --publish--> LIVE --最后 release--> RETIRED
                     |
                     +--cancel--> EMPTY
```

`reserve` 在载荷分配前预约容量，不接管载荷；拒绝不修改控制块。
提供方分配失败或者放弃发布时，先处置自己的载荷，再 `cancel` 归还预约。
`publish` 仅在 TR_OK 时接管载荷、建立首个强引用和释放责任；失败不运行释放回调，保留预约及原载荷所有权。

发布后该控制块不再接受重新预约；已退役句柄不能复活。重新使用其内存必须在上一次最终释放已经完全返回、所有线程均停止访问之后，作为新对象重新初始化，而不是直接改 LIVE 对象。

`clone/slice` 只从调用方已经持有的有效消息取得引用。不能从裸指针、已释放对象或未经同步的外部列表直接取引用。
每个线程只能独占修改自己的消息句柄，句柄交付由调用方建立同步；载荷在持有期间只读。
C 结构体直接赋值不增加引用，API 不承诺识别这种非法别名，更不提供悬空指针安全。
同一被 API 清空的句柄再次释放可检测为 TR_ERR_STATE；合法别名由 clone/slice 创建。

`none_move` 是同步的检查与所有权移交，不是网络发送或异步操作的接受点。
它独立检查解码体与编码体长度限制；两者在 none 模式中数值相同但概念不同。
长度限额为 0 只允许合法空消息；这与既有 budget 的 limit=0 表示只记账、不设硬限额是不同配置。

## 3. 最后释放与预算守恒

同一存储的多个切片/克隆只预约一次完整容量。最后一个引用释放时：

1. 先清空调用方的句柄，再递减引用；
2. 只有 1->0 的调用方获得最终清理责任；
3. 保存预算、容量、回调和参数到局部变量；
4. 同步执行提供方的释放回调；
5. 回调返回后再归还原容量预算，不再访问可能已经被回调释放的消息/控制块。

因此一个仅保留几个字节的切片仍持有整份底层存储的容量。预算不能因为原消息释放或视图变小而提前返还。
回调运行在执行最后一次 release 的线程上；提供方必须保证该回调可以在这个执行域运行。
需要回到 Reactor 的释放、可失败清理、异步回收或池保留容量不属于本切片，不能直接套用这个同步回调。

预算域必须比全部引用和最后释放调用活得更久，不能在回调中销毁它。
预算/引用出现内部失配时返回错误，但 release 已消费句柄，调用方不得以错误返回为由再次释放同一句柄。

本预算仅覆盖提供方声明的载荷存储容量：不包括控制块、调用方栈、分配器额外开销、线程、TLS、内核缓冲或进程 RSS。
本模块不接收不可信网络长度、不修改网络窗口，也不把解码存储容量误当网络信用。
已有计账 Buffer 必须通过独立适配迁移，不能先保留旧账再重复 reserve。

## 4. 独立测试与构建

`test_message` 使用 Xmake 的 `trcore` 构建依赖，但关闭链接继承，仅从实际 sourcebatches 取得一个生产 `message.c` 对象参与链接。
它不链接 `libtrcore.a`，不借其他模块自动解析新出现的 RPC/Channel/Reactor 符号；没有另写编译器命令取代项目构建配置。
同一生产源没有注册为另一个测试翻译单元，避免现有编译数据库对重复生产条目的严格检查被破坏。

```sh
xmake f -c -y -m release --toolchain=gcc
xmake test -v -j1 'test_message/*'
```

该目标仍会先构建 trcore 依赖；这是生产对象复用，不是声称无需构建仓库其余代码。
本地额外用独立编译命令直接验证同一模块。目标隔离链接不能替代完整的头文件可见性、跨模块符号规则和负向依赖门禁；#248 仍开放。

八组测试覆盖：

| 分组 | 核心断言 |
|---|---|
| 预约/取消 | 连续预算拒绝不接管、重复预约/取消拒绝、分配失败归还预约、64 位计账溢出拒绝 |
| 发布回滚 | 未预约、坏长度、缺少回调/数据、输出已持有时均不误接管；可修正重试 |
| none 与别名 | 分别检查两个长度域；失败保留输入输出；成功移交原引用和相同数据地址；禁用分配时仍正常运行 |
| 空消息与边界 | NULL+0 合法消息、末尾零长度切片、嵌套切片、SIZE_MAX 越界、引用上限白盒注入 |
| 嵌入式描述符释放 | 最后回调同时 free 载荷、消息句柄和控制块，函数返回前无再次访问 |
| 并发持有 | 8 线程，每线程 2000 次克隆/释放，各自持有源引用；仅一次最终释放和预算归还 |
| 回调与信用顺序 | 条件变量冻结最后释放回调，其他预约仍被拒绝，回调结束后恢复容量 |
| 参数错误 | 空参数/非法句柄明确失败，不依赖关闭 NDEBUG 后消失的测试操作 |

测试使用 CHECK 而非带副作用的 assert。分配失败自检通过 volatile 函数指针执行真实 malloc 调用：首轮 Clang O2 将未使用分配优化后导致自检失败，已改为显式调用并重新通过；未使用关闭优化或跳过自检掩盖失败。
none 原地址不变和分配截获说明该核心不复制/分配载荷，不是整个网络栈的性能结论。
