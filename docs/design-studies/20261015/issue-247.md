## 1. 从已有测试出发，不另造重复框架

当前 [测试策略](https://github.com/MyBlackHole/c-trpc/blob/130835414f3e00cf97d49ca8af21d7a83c25146d/docs/testing_strategy.md) 已有单元、集成、消毒器、静态分析和性能诊断边界。新增工作是让跨层事件和失效条件可重放，不是机械增加编译选项笛卡尔积。

[SQLite 测试](sources.md#s26) 提示覆盖连续失败；[gRPC FuzzingEventEngine](sources.md#s38) 提供可控事件/时间思路；[LLVM libFuzzer](sources.md#s27) 用输入变异和覆盖反馈寻找反例。libFuzzer 当前维护状态与新功能开发另有说明，本项目只借成熟测试接口，不因选用它就承诺某种长期工具路线。

## 2. 三层验证结构

L1 纯语义参考模型：小范围 Call/方向/终局、预算和操作状态，不运行真实线程；输出应发生的状态与资源责任。模型不能直接复制生产代码分支，否则相同错误会被双方共享。

L2 确定性组件执行：虚拟单调时钟、可控就绪事件、任务队列、连接字节切片与失败注入；驱动实际模块执行，记录随机 seed 和最小化轨迹。替身只替换不可控环境，不替换被验证的协议判断。

L3 真实构建与网络：GCC/Clang、ASan/UBSan、TSan、跨进程、实际 TLS/压缩以及支持平台。真实网络结果不能替代 L1/L2 对关键时序的覆盖；模型通过也不能替代实际产物验证。

## 3. 场景生成与必须保持的属性

事件字母表含 OPEN、MESSAGE、END、STATUS、RESET、deadline、cancel、队列准入、工作完成、策略/连接换代、存储释放、source detach、OOM。合法轨迹与恶意/非法轨迹分开，不能随意重排同一 TCP 字节顺序后将协议错误当正常实现回归。

可做的变形关系：同消息不同分片方式应产生相同合法结果；不同独立流的允许交错不改变各流顺序；失败点平移只改变受影响操作，资源仍守恒；取消后的迟到完成不复活能力。每条轨迹结束驱动到 quiescent，再检查未完成操作、回调和持有额度；外部故意保留的资源要在期望表中显式列出。

有限模型可先选两个流、最小队列和小 generation 位宽探索关键交错；规模与运行预算在实现中记录。有限搜索没有反例不等于无限状态形式化证明。活性测试必须注明公平调度、网络最终恢复和应用最终归还的前提。

## 4. 故障注入和检查器自测

每个适用构造/发送/变换场景至少覆盖第 N 次单次失败与 N 后持续失败；注入点限制在被测资源域，避免把日志或测试自身分配算进错误位置。模拟系统调用必须忠实表达其真实副作用，不能让失败的 close/提交同时产生不可能状态后误诊生产缺陷。

门禁自身也要负向验证：删除一个生产 TU、故意错工具版本/配置、丢失 expected failure、引入私有依赖、伪造测试 count，均需失败。重跑通过不能抹去首个失败；关联可重放序列或明确未解释问题。

## 5. 性能与可观测性

[gRPC 指标](sources.md#s30) 区分调用与尝试；[HdrHistogram](sources.md#s35) 提供有界直方图及采样/聚合思路。普通 Histogram 不天然支持无同步多线程写，不能把单线程示例放到共享热路径。

建议每 owner 记录固定标签/固定桶，控制线程取得安全快照再聚合。至少区分 offered/admitted/completed/rejected，LogicalCall 与 Attempt、网络字节与解码字节、排队时间与业务处理时间、协议已终局但仍持有任务的对象。对未知 Method 和任意远端字符串使用有界类别，不将调用 ID 当指标标签。

开环负载按计划到达时间测量等待，闭环单独报告；不能只记录实际开始之后的延迟隐藏生成器迟发。若使用协调遗漏修正方法，原始记录与估算修正分开，不能把合成样本当实测请求。记录生成器 CPU、未发出请求和统计区间；仅吞吐高但失败/拒绝更多不能算收益。

## 6. 切片与持续运行规则

TEST-A：小模型与轨迹格式，映射每条不变量及 task ID。

TEST-B：可控时钟/I/O/执行替身，复用现有组件测试，不另造一套业务协议。

TEST-C：输入模糊测试和 N/持续故障，保留 corpus、seed、最小反例。

TEST-D：真实集成/平台矩阵与精确产物身份，历史结果不能自动覆盖新 SHA。

TEST-E：分层指标与对等性能，确认诊断不引入私有状态逃逸或无限分配。

PR 跑受影响的有界回归；较大状态探索、长压测按独立执行预算安排。本文未安装新定时工作流，不报告任何模型/消毒器/性能“通过”。阶段能力可关闭，持续回归由 #249 管理。
